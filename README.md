## 🧠 **Filosofía de desarrollo**

Creo en crear software que sea:

* **Claro por dentro** (arquitectura sólida)
* **Atractivo por fuera** (experiencia pulida)
* **Flexible en el medio** (fácil de extender, probar y mejorar)

Escribir buen código no es solo hacerlo funcionar:
es **hacerlo entendible, mantenible y elegante.**
